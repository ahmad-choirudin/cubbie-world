# Cubbie World

Vite + React + TypeScript + Tailwind v3.

## Jalankan (GitHub Codespaces atau lokal)

    npm install
    npm run dev

## Yang perlu kamu isi

- `src/data/projects.ts`: ganti semua `"#"` (3 proyek, X / Telegram / Discord, portfolio, GitHub, email).
- `src/data/outfits.ts` dan `src/data/characters.ts`: nama, kategori, label, dan deskripsi.
- `public/images/characters/`: hero.jpg, outfit-1 sampai outfit-8, dan gambar koleksi.

## Tahap berikutnya

Setelah website dasar stabil: animasi Motion, model .glb dengan React Three Fiber, wallet connection dan NFT minting.
